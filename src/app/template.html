The dataset

Built on every compound, not a convenient subset.

Tox21 is a US inter-agency screening programme that put thousands of commercial chemicals, drugs and pesticides through twelve biological assays. It is the standard teaching set for multi-task learning in chemistry precisely because it is messy: the label matrix is full of holes, and active compounds are a small minority in every single column.

Figures below are computed from the cleaned dataset at page load, not written into the markup. Structures were parsed, salt-stripped, neutralised and canonicalised with RDKit.

Why this is hard

The holes are the problem.

7.3% – 26.0%of each assay column is empty. A blank is not a negative result — it means the compound was never put through that assay. Treating blanks as inactive is the single most common error on this dataset, and it quietly inflates every score.
2.9% – 16.3%active rates. A model that answered “inactive” to everything would score above 84% accuracy on every endpoint and 97% on the scarcest, which is why accuracy is never reported here — only ROC-AUC and PR-AUC.
Masked lossA binary mask multiplies every term of the cross-entropy, so an untested assay contributes exactly zero gradient. Positive classes carry tempered weights, so the rarest endpoints still train without destabilising the shared trunk.

The twelve assays

What each endpoint actually measures.

Seven nuclear-receptor assays test whether a compound interferes with hormone signalling. Five stress-response assays test whether it damages the cell. They differ enormously in how often they return a positive, and that base rate — not the model — sets how hard each one is.

Method

Six decisions that make the number trustworthy.

Any model can post a high score on this dataset by leaking scaffolds between splits or by counting missing labels as negatives. These are the steps that prevent both.

01

Standardise structures

RDKit parses every SMILES string, strips counter-ions down to the largest fragment, neutralises formal charges and writes a canonical form. InChIKeys collapse replicate records so the same molecule cannot appear on both sides of a split.

__NCOMP__ structures retained
02

Featurise

Each molecule becomes a 2,048-bit ECFP4 fingerprint — circular substructure environments at radius 2 — plus nine physicochemical descriptors covering weight, lipophilicity, polar surface area and hydrogen bonding, clipped at the 1st and 99th percentiles and standardised.

2,057 features per molecule
03

Split by scaffold

Compounds are grouped by Bemis–Murcko scaffold, the ring core left after side chains are stripped. A group never spans two splits, and the largest groups are routed to training so they cannot dominate the test set. A leak assertion fails the run if any scaffold crosses.

0 shared scaffolds
04

Mask the loss

A binary mask sits inside the cross-entropy and zeroes every untested assay before the sum, so missing labels produce no gradient at all. Positive weights are square-root tempered, which counters active rates near 3% without letting one endpoint dominate the shared trunk.

12 heads, 1 forward pass
05

Benchmark fairly

Random Forest, ExtraTrees and LightGBM are each fitted per endpoint on exactly the compounds tested for that assay, using the same features and the same split. A deep model that cannot beat those baselines has not earned its complexity.

5 models, identical folds
06

Quantify uncertainty

Every score carries a 95% confidence interval from 1,000 stratified bootstrap resamples that keep both classes in each draw, and a paired test compares models on identical resamples — so a difference is only called real when the interval excludes zero.

1,000 bootstrap resamples
Read every number on this page as an assay result, not a safety verdict. A Tox21 model predicts the outcome of a specific in-vitro assay — one protein target or one cellular stress reporter, in a dish. It does not predict whether a substance is safe or harmful to a person, and nothing here should be used to make claims about any real product, food, cosmetic, medicine or environmental sample. Assay signal is a starting point for further testing, never a conclusion.
